> 对象：接手/维护本项目的内部开发。
> 定位：**索引级**说明，只给"地图 + 最易踩的坑 + 第一动作"。
> 规范唯一源是根目录 `AGENTS.md`（构建红线/命名/同步清单/审计，冲突以它为准，
> 本篇不复述细则，防止双源分叉）。协议唯一源是 `docs/通讯接入.md`。
> 现场用法见 `docs/现场工程师培训手册.md`（改了功能先想手册要不要同步）。

## 一、新人上手路径（按序，半天）

1. 读 `AGENTS.md`（强制前置，角色/红线/构建全在里面）。
2. 读本篇二~四节，建地图；跑一遍回归（第九节），确认环境 OK。
3. 通读 `README.md` 4~6 节（业务流/配置/菜单），对照跑起来的主窗体点一遍。
4. 改第一行代码前，先读第五节（同步清单）——漏一处就是一个现场 bug。

## 二、技术栈与构建

- .NET Framework 4.7.2 / WinForms / C#（**不是** .NET Core，勿引入新语法/API）。
- 关键库：SunnyUI（界面）/ NModbus（Modbus）/ Newtonsoft.Json / System.Management（WMI）。
- 构建（AGENTS 原文，MSBuild 找不到先定位）：
  `MSBuild.exe AgingTestSystem/AgingTestSystem.csproj /p:Configuration=Debug /p:Platform=AnyCPU /t:Build`
- 老式 csproj：**新增 .cs 必须手工登记 `<Compile Include>`**（漏登记报 CS0246），
  纯代码窗体加 `<SubType>Form</SubType>` 即可。
- 文件编码 UTF-8；禁 PowerShell 默认编码写中文文件；不提交运行时数据与机密；
  不主动 commit/push；改完必构建；注释写给小白看（做什么+为什么+怎么改）。

## 五、三套同步清单（本项目最高频返工点，逐项打勾）

**加 App.config 项（五处）**：`DeviceConfig` 属性 + `App.config` key（含中文注释）
+ `MainForm` 读取 + `SettingsForm`（`_boolKeys` **和** `ValidateValue` 布尔分支两名单
+ 都要进 + `_descriptions` + `_categories`）。另给 `_descriptions` 写清"现状是什么/
改了会怎样"（设置表 tooltip 全覆盖，超 40 字走 `WrapTooltip`）。

**加工艺策略 key（枚举型，另一套）**：`PolicyEnums` 枚举 + `DeviceConfig` 属性
+ `ProjectPolicyStore.PolicyKeys`（唯一名单）+ `EnumOptions` 下拉选项
+ `App.config` key + `MainForm` 读取（`ParsePolicyEnum` 非法兜底现状）
+ `SettingsForm`（`_descriptions`+`_categories`+`ValidateValue`+`CreateValueCell`
下拉分支，不进 `_boolKeys`）。

**配方加字段（三窗链）**：`RecipeConfig` → 录入三窗（`RecipeManagerForm` /
`BatchRecipeForm` / `StationSettingsForm`：输入框+保存+回填+检索回调+头部 ASCII 图）
→ `SetStationRecipe` → `StationInfo`（+`Clone`）→ `ApplyStationInfo`
→ `BarometerData`（+`Clone`）。另注意 `SetStationRecipe` 只认 null=保持，
下发 0 就是定格 0（V1.72.2 血泪）。

## 六、判定逻辑写哪（V1.67 收紧，无例外）

策略执行侧一律先加 `AgingSequencer` **纯函数**并同步用例
（`BuildStartBlockText` / `MapAlarmResult` / `ComputeResumeDurationSeconds` /
`ValidatePolicyCombination` 类），`DeviceManager` 只做"调用决策 + IO + 日志"。
直接写 UI 层的判定=单测够不着，复查必搬（V1.84.1 实锤：破空阀碰撞）。
快照加字段同步列"哪些状态变迁写快照"；持续计时状态变迁必调 `ResetStation`。

## 七、UI 红线摘要（细则见 AGENTS，只记"什么不能干"）

1. SunnyUI 换肤：新窗打开前调一次 `ThemeManager.ApplyTo`；按钮语义色不动；
   `is Button/TextBox/ComboBox` 认不出 Sunny 控件，按类型名走分支。
2. UIForm 标题占 35px：绝对布局下移 35 + 加高 + MinimumSize；居中只调 X 不动 Y。
3. Designer 三军规：`InitializeComponent` 内禁注释；与 VS 口径不一致以重写版为基线；
   `.resx` 别手删；禁 `AddRange(裸标识符)` / `= xxx.Range.Min/Max` /
   `ZoomScaleRect`+`Font` 混搭；纯代码窗补无参构造给预览。
4. 自绘三不：不用 `DoubleBuffered`（TextRenderer 离屏 2.2ms/处）、变换矩阵下不挂
   `TextRenderer`、度量全放布局态；裁剪按图元包围盒判交；坐标一律锚定（`PanelLayoutConfig` 类头）。
5. Dock 的 Fill 必须最后布局（统一 `BringToFront()` 一次）；列表画布缩放抄
   `IoRemapGraphControl`（DPI×zoom 进布局基准）。
6. 动态重建走 `ControlDisposeHelper.DisposeAllAndClear`（禁手写 foreach）；
   非模态 popup 的 FormClosed 里 `finally Dispose`；后台/定时/订阅四模式自查
   R5/R6/R7；新非模态弹窗在 `$SafeShowKeys` 登记。
7. 界面文件头补 ASCII 布局图（每次改界面同步）；tooltip 全覆盖（标签+输入框两边挂）。
8. 叠放取"子控件"方案（挂进宿主 Controls，天然浮上层）；自绘图标不用 emoji；
   未 Show 窗体 `PerformClick` 是空操作，回归直接调 handler。

## 八、落盘与健壮性（V1.84 大扫荡，新增持久化先想这三条）

- 运行时 json 一律 `AtomicFile.WriteAllText`（`File.Replace` + 清残留 tmp），禁裸写。
- 路径一律 `BaseDirectory` 绝对路径；测试隔离走 `BaseDirOverride` 测试缝（finally 复位）。
- 规则解析三防护（`||` 切分枚举合法组合 / 严格变量模式 / 长度嵌套上限）；
  项目名校验只认 `IsValidProfileName`；IO 写失败先写后清；时钟作差负跨度钳零；
  对外只吐副本（User/账号 Clone）；即时写失败留痕（CSV/LOG）。
- 用例假绿三查：探针先验有效、存在性断言看前后差值、新逻辑无用例=没修。

- 公式逐字节照抄 HJVision（`Encrypt` MD5 前 15 字节；设备ID码=`ID+"A"` /

## 十二、激活码发放教程（V1.87：与 HJVision 同一套《获取激活码》工具，公司内部）

> 对象：给客户开户/续期的商务/技术。判定细节看 AGENTS"软件授权铁律"全文；
> 工具用法与 HJVision 完全一致（设备ID→设备ID码→设备码→30天码/永久码）。

### 0. 先搞清分工（一句话）

- 发码用《获取激活码》工具（公司内部，算法=MD5 公开函数，工具本身不含密钥，
  **工具流出=谁都能发码，管好工具**）；客户侧只需要做一件事：在【关于→软件授权】
  报"设备ID"和"设备码"。
- 无试用：新机出厂必须先开户（手写 ini 两键），否则每小时弹"新设备请联系厂商激活"。

### 1. 新机开户 3 步（出厂/换工控机时做）

| 步 | 动作 | 说明 |
| :--- | :--- | :--- |
| 1 | 拿到设备ID | 客户激活窗"设备ID"（WMI 第一块 CPU 的 ProcessorId），或实施现场抄 |
| 2 | 算设备ID码 | 工具"设备ID"框粘入→自动算出"设备ID码"（=`Encrypt(ID+"A")`） |
| 3 | 手写 ini | 客户机程序目录的 `MainSetting.ini`（首次运行自动建好空模板，只填值不建文件）写 `[RunHash]` 段：`RunHash1`=设备ID码；`RunHash2`=`Encrypt(ID+"0")`（30天起点，工具用设备码算：设备码=`Encrypt(ID+"1")`恒定）或 `Encrypt(ID+"ALL")`（永久） |

### 2. 日常续期 2 步（客户报"软件已过期"时）

| 步 | 动作 | 说明 |
| :--- | :--- | :--- |
| 1 | 拿到设备码 | 客户激活窗"设备码"（恒定不变，可沿用上次记录） |
| 2 | 发激活码 | 工具"设备码"框粘入→点确定→"30天激活码"或"永久激活码"发客户；客户在激活窗输入点激活即成（错码静默无提示，让客户重输） |

### 3. 常见失败对照表（先查这里再问人）

| 现象 | 原因 | 怎么办 |
| :--- | :--- | :--- |
| 新机一直弹"新设备" | `MainSetting.ini` 没建 / `RunHash1` 与本机对不上 | 按第 1 节重写两键（注意文件放程序目录，不是 `Projects/`） |
| 激活码输了没反应 | 错码静默无操作（与 HJVision 一致） | 核对设备码是否本机、码是否粘全 30 字符，重输 |
| 过期后用户权限按钮灰了 | 到期置灰本轮不恢复（与 HJVision 一致） | 续期后**重启软件**重查 |
