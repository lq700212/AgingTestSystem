# 老化测试系统 · 现场工程师培训手册

> 对象：在产线操作、处理报警、做首件/换型设置、配合联调的现场工程师。
> 目标：学完能独立完成"开机→生产→报警处理→交班查询"全流程，知道什么能点、什么不能点。
> 依据：README / `docs/通讯接入.md`（V1.86.3现状）。
> 协议寄存器细节不在此展开，查 `docs/通讯接入.md`（唯一协议文档）。

## 一、这套软件是干什么的

72 个工位做"真空吸附 + 载台上电"老化测试。软件每秒轮询 72 台气压表压力，
按配方自动走"抽真空→上电计时→到时下电"流程，异常自动关阀断电并标故障。

| 硬件 | 规模 | 软件里对应什么 |
| :--- | :--- | :--- |
| 真空负压表（气压表） | 72 台 | 主界面 72 个面板，每台显示压力/状态 |
| 真空电磁阀 | 72 路 | 软件自动开关，无手动按钮 |
| 载台上电（继电器） | 72 路 | 真空到位+延时到才自动上电 |
| 冷却送风机 | 1 台 | 有在测工位即自动运行，全停才停机 |
| 扫码枪 | 1 把 | 扫 SN 绑定工位 |

## 二、登录与权限

1. 点菜单 **用户权限** → 选角色 → 输密码登录。
2. 默认账号（初始密码均为 `123456`，首次登录后找管理员改掉）：

| 角色 | 能干什么 |
| :--- | :--- |
| 操作员 | 启动/停止/复位/查历史，日常生产 |
| 技术员 | 操作员全部 + 通讯测试/送风机测试/配方设置 |
| 管理员 | 全部 + 系统设置/用户管理/项目切换 |

3. 交班时在用户权限里切换账号即可。

## 三、主界面认识

- **工位面板区（9×8=72 格）**：每格显示工位号、SN、压力、状态文字。
  **认状态以文字为准**：`空闲 / 抽真空 / 老化计时 / 已完成·待取料 / 故障` 等；
  故障格标红、完成格标蓝，一眼定位。
- **右侧"操作"区**：批量设置配方 / 录入批号 / 启动运行 / 停止运行 /
  报警复位 / 下料判定 / 全部停止(急停）。
- **顶部菜单**：用户权限 / 参数设置 / 日志记录 / 关于。
- **底部状态栏**：连接状态（"在线"；大面积离线标红即通讯断了，先查线缆，不要一上来就重启工控机）。

## 四、标准生产流程（8 步）

```
①录入批号 → ②扫码绑定工位↔SN → ③设配方并下发 → ④启动运行
→ ⑤巡检监控 → ⑥到时自动下电 → ⑦取料 → ⑧复位回空闲
```

| 步骤 | 操作 | 说明 |
| :--- | :--- | :--- |
| ①录入批号 | 操作区 **录入批号** | 一批料录一次，后续追溯靠它 |
| ②绑定 SN | 操作区 **录入批号** → 弹出的录入窗/绑定窗里扫码 | 扫码枪扫产品 SN 自动填充到对应工位，一台一码 |
| ③设配方 | 操作区 **批量设置配方**（多台）或面板 **设置**（单台） | 配方=延时开启+老化时长+负压阈值；见第七节 |
| ④启动 | 选好工位 → **启动运行** | 只开真空阀、不带电；时长/延时/阈值此刻定格 |
| ⑤监控 | 看面板文字+压力 | 抽真空→到时自动上电计时，无需人工干预 |
| ⑥完成 | 自动 | 到时自动下电+关阀，面板变蓝"已完成·待取料"，日志记 PASS |
| ⑦取料 | 人工取下产品 | 无自动破空/无响铃，残压还在，徒手取（拿不下报工艺改泄压配置） |
| ⑧复位 | **报警复位**（或重扫码绑新 SN） | 蓝屏/红屏必须复位才回空闲，停止键清不掉 |

关键语义（背下来）：

- **参数启动瞬间定格**：④之后再改配方，只对新启动的工位生效，在跑的不受影响。
- **配方优先、全局兜底**：延时/时长/阈值先看配方，配方没填才看全局设置。
- **时长填 0 = 不限时长、永不自动完成**：烧屏/老化必须填时长，启动时软件会警告。
- **SN 为空也能启动**（警告），但追溯无 SN，正式生产必须绑定。

## 五、面板选中与"设置"按钮

- 面板空白处**长按约 0.8 秒**选中该工位（出现选中框）；有选中时长按空白处=取消全选。
- 面板上的 **设置** 按钮是智能分流，不用提前选：
  - 所在工位未选中 → 先把它加入选中；
  - 只选中 **1 台** → 弹该台的工位设置窗（SN/配方/延时/极限温度/负压阈值）；
  - 选中 **2 台及以上** → 弹批量设置配方窗。
- 每行还有"全选"按钮，一整行一起操作。

## 六、报警与异常处理

### 6.1 单台三阶段（正常长这样）

```
点启动 → 只开真空阀（不带电，抽真空阶段）
       → 真空到位 且 距开阀≥配方"延时开启" → 自动上电计时
       → 时长到 → 自动下电关阀 → 蓝屏待取料
```

### 6.2 报警种类与动作（统一：关该台阀+断电+标红，只触发一次）

| 报警 | 含义 | 现场处置 |
| :--- | :--- | :--- |
| 压力越限（产品 FAIL） | 真空变差，超过阈值 | 查气管松/漏/产品没放好，处理后复位重测 |
| 真空建立失败（产品 FAIL） | 开阀 15 秒还没到位 | 同上；批量出现查气源总阀 |
| 通讯失联（设备异常，不记产品 FAIL） | 该表连续 3 次读不到 | 查该表电源/地址拨码/485 线；换表后复位 |
| 超温联停（可选，默认关） | 送风机温度超限 | 查风道堵塞；全线停机，温度恢复后复位 |

合格口径：**全程无报警 = PASS**；通讯失联不冤枉产品，只记设备异常。

### 6.3 三个易混按钮

| 按钮 | 效果 |
| :--- | :--- |
| 停止运行 | 中止在测/抽真空，回空闲，**不清红蓝屏、不记判定** |
| 报警复位 | 红（故障）/蓝（完成）回空闲，必须用它 |
| 全部停止（急停） | 全关阀+全断电+停风机+清任务快照，带确认框；非紧急不用 |

### 6.4 断电/异常退出恢复

重启后若弹恢复提示：选**整台重测**（已跑作废、满时长重跑，默认策略）
或**放弃**（安全关阀断电）。按当班工艺要求选。

### 6.5 下料判定按钮

本项目默认**自动 PASS**，该按钮平时点了只会提示，不用管。
只有工艺切到"待判定"模式后，完成的台需在这里人工录 PASS/FAIL+不良代码+处置。

## 七、配方管理

- **配方管理**（参数设置 → 配方管理）：建配方改配方，添加/更新/删除自动存盘，
  无"保存"按钮。配方字段：延时开启 / 老化时长 / 负压阈值 / 显示模式（仅记录用）。
- **批量设置配方**：把配方下发到选中的工位。"加入队列"=存配方+下发。
- **工位设置**（单台）：SN/配方/延时/极限温度/负压阈值，可单独微调一台。
- 负压阈值填 0 = 永远"到位"，真空保护形同虚设；老配方升级后显示 0 的必须人工复核再填。

## 八、工艺策略预置 A/B/C（傻瓜入口）

参数设置 → **工艺策略** → 顶部预置下拉，出差/换型先套，不用逐项配：

| 预置 | 场景 |
| :--- | :--- |
| A 标准 | 量产首试；被拦按提示填（时长/SN/风机） |
| B 宽松 | 试产跑起来；误报多切 B |
| C 严格 | 出货放行；开超温联停，需先填本机超温上限 |

策略窗的图只读不画（拓扑锁死，防误删安全联锁）；点节点改配置，
保存与系统设置表是同一条路。MES 上报节点只看不动，自定义规则页不动它。

## 九、历史记录与报表

- 日志记录 → **历史记录**：读 CSV，可按条件查启动/报警/完成/判定全过程。
- **导出**按钮按"报表列"配置生成 xlsx，直接发质量。报表列找管理员配，
  历史窗里导出旁就有"报表列设置"按钮。
- 主窗体下方的操作日志框与 `Logs\AppLog_*.log` 逐行一致，报修时把当天 log 发出来。

## 十、测试与调参窗口（技术员及以上）

| 窗口 | 入口 | 用途 | 注意 |
| :--- | :--- | :--- | :--- |
| 通讯测试(IO) | 关于菜单 | 单点点动 DO（阀吸合声/继电器灯）、读 DI、通道遍历、备用通道映射 | 点灯会**真动作**，确认对应阀再点；备用通道烧了才用 |
| 送风机测试 | 关于菜单 | 定值启停、看温湿度 | **测试中不要手动停**，会被采集循环立即重启；在全停维护时用 |
| 公共参数 | 参数设置菜单 | 统一改全部气压表负压阈值：输一个 kPa 值，设备（0x0010）+ 软件报警阈值两边一起写 | 72 台逐台写较慢，后台跑；失败名单按提示重进再写一遍 |

## 十一、系统设置与项目切换（管理员）

- 关于 → **设置**：全部配置项按分类编辑，悬停有说明；保存即生效，
  连接类自动重连，只有设备数量/布局/模拟开关等结构型需重启。
- 参数设置 → **项目切换**：换产品/换线切项目档案（配方/策略/布局跟着换，
  用户/日志不动）；**在测时禁止切换**。
- 用户管理：增删操作员/技术员，改初始密码。

## 十二、软件激活（V1.87：与 HJVision 同一套工具）

- 无试用：新机先找商务开户，否则每小时弹一次"新设备请联系厂商激活"（不拦生产）。
- **报码**：关于 → 软件授权 → 把"设备ID"和"设备码"报给商务。
- **激活**：拿到激活码 → 同一窗口"激活码"框输入 → 点**激活**；
  永久显示"永久使用"，30天显示"剩余使用天数 / N"（N 会随运行小时减少）。
- 错码输了没反应（静默的），核对 30 个字符重输。
- 过期/新设备会置灰"用户权限"按钮：续期或开户后**重启软件**恢复。

## 十三、常见故障排障速查

| 现象 | 先查 |
| :--- | :--- |
| 状态栏全红"离线" | 网线/网段（IO 耦合器 192.168.1.20:502 同网段）、ST 灯闪绿=接触不良 |
| 某台一直通讯失联 | 该表电源/地址拨码/485 A-B 是否反了/共地；批量写超时=设备问题不是软件 bug |
| 找不到 CH340 串口 | USB 没插/驱动没装（要认 VID_1A86/PID_7523 的口） |
| 串口 Access denied | 端口被别的软件占了 |
| 压力显示巨大正数 | 先查小数位/缩放配置（多在换表之后），仍不对记下台号上报开发 |
| 风机连不上 | 开关/网线/IP（端口是 50000 不是 502）；风机是可选设备，不影响开工 |
| 扫码枪扫不出 | 确认枪是虚拟串口模式；串口被占用也会 Access denied |
| MES 收不到数 | 先看启动日志 MES 状态行（开了没、往哪发、Mock 还是真发）；Mock 模式只写 CSV 不真发 |

## 十四、每班点检（5 分钟）

1. 状态栏在线，面板无大面积失联，离线台列清单报修不等人。
2. 扫码枪随便扫一条，有填充即正常。
3. 抽一台看压力跳动（采集 1 秒一跳，定住不动查该表）。
4. 昨天 CSV/历史记录能打开，追溯链不断。
5. 激活窗"剩余使用天数"小了就催商务续期。

## 十五、禁忌清单（不要做的事）

1. 测试中不用送风机测试窗手动停风机（会被自动重启）。
2. **两种阈值绝不混用**：软件报警阈值（kPa，不写设备）≠ 气压表设备阈值（写 0x0010）。
3. 烧屏/老化时长必填，0 = 永远跑不完。
4. 急停会清任务快照，非紧急不用"全部停止"。
5. 中途改配方不影响在跑的台，要生效就重启动。
6. 通讯测试点动 DO 是真动作，别乱点整排遍历（确认→单点→听声/看灯）。
7. 激活码 30 个字符，抄全再输（错了没提示）；`MainSetting.ini` 别删别拷到别的机。
