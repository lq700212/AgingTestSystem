## 附图：软件里现在跑的就是这个逻辑（单台工位视角，与代码逐条对过）

```
空闲 ──[点启动]──► 只开真空阀，不带电（抽真空Vacuuming阶段）
                          │
         ┌────────────────┼──────────────┐
         │                │              │
    真空到位 且        超时还没到位      连续读失败N次
    延时开启到       （默认15秒可配）   （默认3次可配）
    （等于阈值              │              │
     算到位）               ▼              ▼
         │           报压力越限FAIL   报设备异常
         ▼           关阀＋断电       关阀＋断电
    载台上电，         面板标故障红    面板标故障红
    开始计时           永不带电        不记产品FAIL
    （计时起点=上电时刻，
    参数启动瞬间定格）
         │
         ├──── 老化中失压/掉线同样报警（与抽真空阶段同动作）──►FAIL/设备异常
         │
    时间一到（配方时长优先、全局兜底；都为0=不限时长永不自动完成）
         │
         ▼
    自动下电＋关阀（关阀≠泄压，残压还在，无自动破空/无响铃）
    面板淡钢蓝"已完成"（日志记PASS·待取料）
```

- **停止 vs 复位（易混）**：手动停止只中止Testing/Vacuuming/Aging回空闲，清不掉红/蓝屏；
  故障红/完成蓝必须按“报警复位”或重新扫码绑SN才回空闲。急停=全部输出OFF+停风机，但红/蓝标记同样保留到复位。
- **断电来电**：重启询问“整台重测（满时长重跑，已跑作废） / 放弃（安全关阀断电）”。
- **合格口径**：全程无报警＝PASS；压力越限/超时＝FAIL（产品责任）；通讯失联＝设备异常（不记产品 FAIL）。
  （真空类可切装夹异常 / 完成可切待判定，下图是缺省行为。）
- 图里“延时开启/老化时长/负压阈值”配方优先、全局兜底，启动瞬间定格，中途改配方不影响在跑的台。

3. **定格语义接受吗？（原Q18，大改）**
   现状：启动瞬间抄配方，中途改配方旧台按旧参数跑完。接受即签字，不接受走改造清单重议（无"实时跟随"开关）。

    这个应该没问题的，中途改配方一般是不允许吧，也容易出问题，你分析呢？

    【结论：保持定格，已落地V1.74】启动定格是工业常识（同批同参数是追溯底线；
    阈值中途漂移会造假PASS/假FAIL；快照语义本就是启动定格）。另加小护栏：
    批量/工位窗在测下发提示"仅对新启动生效"，配方管理窗更新提示同语义。

4. **老化画面是什么？（原Q20余，PG二期）**
   白场 / RGB 循环 / 棋盘格 / 视频，分段吗？`DisplayMode`现只记追溯（配方三窗+日志），不控PG切画面。
   时长部分已可配不在此列（配方设默认值 + 0时长硬拦截，防烧屏无限点亮）。

    这个也没有做要求，一般这种项目会要求这个吗？你要不也做成可配置的，反正客户自己选

    【已落地V1.74·记录层】行业惯例老化段画面由治具驱动板/PG 固定输出，上位机只记追溯，
    故 `DisplayModes` 字典可配（跟项目，缺省 白场/红/绿/蓝/灰阶/RGB循环/棋盘格/视频）
    + 三窗真下拉单选（手打进不来，老值追加可见、存时拦整改）+ 保存校验。
    【V1.75】字典本身配法：设置表该行点出列表弹窗（一行一个选项，可改/增/删，
    空配置显示预设行）——下拉配字典会循环定义，故字典用列表编辑。
    【V1.75】维度开关 `DisplayModeEnabled`（跟项目，默认关）：当前项目没提画面，
    三窗隐藏该行+布局收缩零打扰；有要求的项目打开即回下拉+字典。
    上位机不控 PG（无协议），画面分段/视频走二期。

5. **改造池要哪几行？（P2，二期）**
   P2-❽ 分组错峰上电（无配置，需排期）；P2-❾ 三色灯/蜂鸣器（蜂鸣已可配无需硬件，灯柱硬件另计）；
   烟感走预留 DI，硬件另计。

    这是什么东西？详细解释给我

    【解释·本次暂缓施工，只落文档】
    - ❽错峰上电：72 台条件一到同时上电，冲击电流大。分组延迟上电（如每组间隔 N 秒）
      需新增"分组+间隔"配置与上电调度，现状无此逻辑。排期约 1~2 天（含回归）。
    - ❾灯柱：红（故障）/绿（完成）/黄（待判定）+ 蜂鸣，装车间柱子上远距离可见。
      蜂鸣已可配（`CompletionAction` 带 Beep，无硬件）；灯柱需硬件 + 灯逻辑 +
      DO 点位。注意 `0x2009` 现在既是备用通道映射目标又是灯预留——真做时点位
      规划避冲突（另选预留寄存器或与备用映射互斥校验），否则点灯即烧映射。
    - 烟感：预留 DI 接烟雾传感器，超限全线急停 + 报警。硬件另计；软件可用
      自定义规则 `di0` 曲线救国（持续秒拉长防误报），正式烟感配置等硬件到了再做。
