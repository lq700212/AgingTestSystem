# 问题确认清单

## 附图：软件里现在跑的就是这个逻辑（单台工位视角，与代码逐条对过）

```
空闲 ──[点启动]──► 只开真空阀，不带电（抽真空Vacuuming阶段）
                          │
         ┌────────────────┼──────────────┐
         │                │              │
    真空到位 且        超时还没到位      连续读失败N次
    延时开启到       （默认15秒可配）   （默认3次可配）
    （等于阈值              │              │
     算到位）               ▼              ▼
         │           报压力越限FAIL   报设备异常
         ▼           关阀＋断电       关阀＋断电
    载台上电，         面板标故障红    面板标故障红
    开始计时           永不带电        不记产品FAIL
    （计时起点=上电时刻，
    参数启动瞬间定格）
         │
         ├──── 老化中失压/掉线同样报警（与抽真空阶段同动作）──►FAIL/设备异常
         │
    时间一到（配方时长优先、全局兜底；都为0=不限时长永不自动完成）
         │
         ▼
    自动下电＋关阀（关阀≠泄压，残压还在，无自动破空/无响铃）
    面板淡钢蓝"已完成"（日志记PASS·待取料）
```

- **停止 vs 复位（易混）**：手动停止只中止Testing/Vacuuming/Aging回空闲，清不掉红/蓝屏；
  故障红/完成蓝必须按“报警复位”或重新扫码绑SN才回空闲。急停=全部输出OFF+停风机，但红/蓝标记同样保留到复位。
- **断电来电**：重启询问“整台重测（满时长重跑，已跑作废） / 放弃（安全关阀断电）”。
- **合格口径**：全程无报警＝PASS；压力越限/超时＝FAIL（产品责任）；通讯失联＝设备异常（不记产品 FAIL）。
  （V1.67 起均为策略缺省：真空类可切装夹异常 / 完成可切待判定，见本节末落子；下图是缺省行为。）
- 图里“延时开启/老化时长/负压阈值”配方优先、全局兜底，启动瞬间定格，中途改配方不影响在跑的台。

## 一、问题确认

### 对工艺

1. **真空到底干什么用的？**
   当面问："漏气这台货，你们算治具问题还是产品不良？"
   - 治具问题 → 现状不动，只验阈值参数。
   - 产品不良 → 报警要关联 SN 记不合格，回来改判定逻辑（约 0.5~1 天）。
   追问一句："摆料时产品靠什么固定？一松手掉吗？"掉 → 加回"装夹预吸附"入口（带压力监控）。

2. **载台给产品供什么电？要不要监测电流？**
   当面问："多少V？直流交流？谁供电？老化中看不看电流/功率？"
   - 要回采 → 加电流表通讯，最大工作量项，单独排期，**不当场承诺时间**。

3. **送风是加热还是冷却？温度谁说了算？超温停单台还是全线？**
   - 软件设温 → 现协议无写温度寄存器，需找风机厂商，先记二期。

4. **老化合格谁说了算？在哪看结果？**
   现状口径：全程无报警=PASS、压力报警=FAIL、失联=设备异常（不记产品 FAIL）。
   只确认：接受否 + 判定人 + 结果在哪看（屏幕/报表/MES）。

### 对操作员

5. **一批放多少？做完一个换一个还是一批同进同出？批号怎么定？混批吗？**
6. **到时完成后你们希望怎样？自动下电够吗，要不要自动泄压/响一声？**
7. **报警的货现在怎么处理？复位谁来按？**

### 对质量

8. **报表要什么样？最好直接拿一张现有纸质/Excel 照抄。**
   现状只有 CSV 明细 + 历史查询；直通率/曲线/SN 追溯单都要现做。

### 对电气/IT

9. **载台供电方式 + 真空管路走向 + 送风管道，拍照。**
10. **MES/ERP 有无硬性对接要求？接口形式？**

### 补充确认点

11. **老化中掉真空停不停？**
    现状：抽真空阶段和上电老化中失压/掉线同样关阀断电（压力类=FAIL，失联=设备异常）。只确认接受否。
12. **15秒超时 + 连续3次失联够吗？**
    现状默认值，可在系统设置改。当面测一次从常压抽到阈值要几秒，回填§三参数表。
13. **所有配方启动时间都大于0吗？空SN/空配方让不让启动？**
    现状：配方与全局都为0=不限时长、永不自动完成；空SN/空配方也能点启动。要不要软件拦截？
14. **完成/故障回空闲谁来按？**
    现状：手动停止清不掉红/蓝屏，必须按"报警复位"或重新扫码才回空闲。定死按的人，列入培训。
15. **完成后产品徒手能拿下吗？（关联Q6）**
    现状：关阀≠泄压，无自动破空、无响铃。现场试一次拿不拿得下，决定加破空阀/声光否。
16. **风机断连/超温允不允许继续跑？（关联Q3）**
    现状：风机掉了测试照跑只记一行日志；极限温度默认0=禁用。回填极限温度，定断连阻断否、超温联停否。
17. **DI硬件触点并入报警吗？**
    现状：`UseDiAlarmContact=false`仅显示不联锁。开了要先确认常开/常闭+NPN电平，否则误报/漏报。
18. **定格语义接受吗？**
    现状：启动瞬间抄配方，中途改配方旧台按旧参数跑完。接受 / 不接受（不接受=大改，排期重议）。

## 四、MicroLED 烧屏锚（V1.65 调研推断，现场只答 yes/no，不动代码）

- **客户身份推断**：合肥显耀 = JBD（显耀股份）合肥工厂，产品为 0.5 英寸以下 MicroLED 微显示屏
  （AR 眼镜/HUD/微投影用，合肥一期 2023-10 竣工、规划年产 1.2 亿套）。设备标签"烧屏"=
  显示行业对"通电老化"的俗称（非 OLED 残影缺陷）。本设备定位=**老化段（点亮+计时+保护+追溯），
  光学判定在后道检测设备**（JBD 2026-03 与精测电子战略合作，精测做点灯检测/Demura）。
- **形态推断**：72 小工位（电视屏物理上放不下 72 块）+ 真空吸附固定微小模组 +
  真空到位才上电（= 探针/pogo 接触保护）+ 载台只供电不控画面（画面由治具驱动板/外部 PG 给）。
- **风险推断**：MicroLED 微显示亮度极高、发热大，72 台 24h 点亮 + 温度只显示不联锁，
  是当前最大安全缺口（见 Q21）。

19. **真空用途 yes/no**：我们的推断=吸附固定+探针接触确认；漏气算治具（可重测、不记产品 FAIL）？
    - yes → 真空失败改记"装夹异常"（P1-❸，纯软件 0.5 天）。
    - no（算产品不良）→ 现状不动，只验阈值参数。（关联 Q1）
20. **老化工艺回填**：老化时长几小时？画面是什么（白场 / RGB 循环 / 棋盘格 / 视频，分段吗）？
    现状时长全 0=不限时长永不完成，对烧屏=无限点亮（过老化+火灾风险），必须改为必填拦截。
    - 回填 → 配方设默认值 + 启动拦截 0 时长（P1-❺，0.5 天）+ 配方加"显示模式"字段追溯（P2-❼）。
    （关联 Q13）
21. **断电续跑 + 超温动作二选一**：①断电后来电"续跑（补足剩余时长）/重测"能接受续跑吗？
    （现状整台重测：浪费产能 + 同一批衰减算两次，影响后道 Demura 基准。P1-❻，约 1 天）
    ②超温停单台还是全线？（现状只显示不限停；风机温度+配方极限温度现成，只差接进报警。
    P1-❹，纯软件 1 天；烟感走预留 DI，硬件另计。关联 Q3/Q16/Q17）
    （关联 Q11）
22. **下料判定口径**：现状到时自动记 PASS。显示行业惯例"老化≠合格"（后道必检坏点/亮暗点/
    线/闪烁/Mura/色偏），接受改成"完成=待判定，下料扫码录 PASS/FAIL+不良代码"吗？
    不接受=追溯数据持续假阳性。（P0-❷，约 1~2 天。关联 Q4）

**纯软件改造池（现场签字后按此排期，电流回采/MES 只能二期）：**
P2-❽ 分组错峰上电；P2-❾ 三色灯/蜂鸣器（0x2009 预留，灯柱硬件另计）。
