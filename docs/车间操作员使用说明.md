# 老化测试系统 · 车间操作员使用说明

## 一、这套软件是干什么的（一分钟看懂）

一句话：**管 72 个工位做"真空吸附 + 通电老化"测试，时间到了自动断电，坏了自动报警。**

| 车间里的东西 | 数量 | 在软件里长什么样 |
| :--- | :---: | :--- |
| 真空负压表（每台看真空够不够） | 72 台 | 主界面 72 个小格子，一格就是一台 |
| 真空电磁阀（吸住产品） | 72 路 | 软件自动开关，你不用管 |
| 载台电源（给产品通电老化） | 72 路 | 延时>0：吸稳＋延时到才自动通电；延时=0：阀和电同时开、直接计时 |
| 冷却送风机（给产品吹风降温） | 1 台 | 有一台在测就自动转，全停才停 |
| 扫码枪（扫产品条码） | 1 把 | 扫一下，号码自动填进格子 |

你要做的事只有四件：**录批号 → 扫码绑工位 → 设配方启动 → 到时间取料**。中间抽真空、上电、计时、断电，全是软件自动的。

## 二、开机和登录

1. 双击桌面图标启动软件，稍等十几秒（软件在连设备）。
2. 点顶部 **【用户权限】** 按钮 → 选择你的角色 → 输入密码 → 点【确认】。

![操作员登录窗口](images/02-login.png)

3. 初始账号密码（第一次登录后找管理员改掉自己的密码）：

| 角色 | 用户名 | 初始密码 | 你能干什么 |
| :--- | :--- | :--- | :--- |
| 操作员 | operator | 123456 | 启动、停止、复位、查记录：日常生产够用了 |
| 技术员 | technician | 123456 | 再多：配方设置、通讯测试 |
| 管理员 | admin | 123456 | 什么都能动：系统设置、用户管理 |

4. 记住一句话：**登录不上先看是不是选错了角色**（用户名和角色要对上），再问班组长，不要反复乱试。

## 三、主界面认识（四个区）

![软件主界面](images/01-main.png)

打开软件你看到的就是上面这张图，分四个区：

- **中间大格子区（72 格）**：一格 = 一个工位。每格显示工位号、真空压力、产品条码（SN）、配方名、上电/真空块。**认状态看格子底色**，下面第五节有对照表（白＝空闲/浅黄＝测试中/浅粉＝故障/淡钢蓝＝完成待取）。
- **右边"操作"区**：你每天点的按钮全在这里：批量设置配方、录入批号、启动运行、停止运行、报警复位、下料判定、全部停止（急停）。
- **顶部菜单栏**：用户权限 / 参数设置 / 日志记录 / 关于。操作员常用的只有【用户权限】（换班登录）和【日志记录】（查历史）。
- **底部状态栏**：看"在线 72/72"。如果大面积变红、显示离线很多，**先查网线和设备电源，不要一上来就重启电脑**，下面有排障表。

右边还有一块"监视"区：显示送风机连上没有、温度多少，平时看一眼就行。

- **自适应显示**：中间格子会按窗口宽度自动放大顶满（字跟着变大变小，最小不小于能看清）；高度看不全就上下滑动看，列数固定 8×9 不动。窗口拉宽/最大化会自动跟，不用管。

## 四、每天生产标准流程（8 步，照着做）

```
①录入批号 → ②扫码绑定工位和产品 → ③设置配方 → ④选中工位点启动
→ ⑤巡检看着 → ⑥时间到自动断电 → ⑦取下产品 → ⑧复位回空闲
```

### 第 ① 步：录入批号

点右边 **【录入批号】**，弹出下面这个窗口，把这一批料的批号输进去（或扫码），点确定。

![录入批号窗口](images/03-inputlot.png)

- 一批料只录一次，后面查记录、追质量全靠这个批号。
- 输错了问班组长改，不要将错就错往下走。

### 第 ② 步：扫码绑定（工位 ↔ 产品一一对应）

还是在录入批号弹出的窗口里继续操作（或点 ID 绑定），窗口长这样：

![扫码绑定窗口](images/04-idbinding.png)

- 做法：拿扫码枪"滴"一下产品条码，号码自动填到对应的工位格里。**一台产品占一个工位，一个格子只绑一个码。**
- 扫完看一眼格子里的 SN 对不对得上你手里的产品。
- 扫码枪扫不出？先看枪的线插没插、软件里扫码枪功能开没开，搞不定叫技术员。

### 第 ③ 步：设置配方（告诉软件"测多久、多大真空算合格"）

配方就是"测试要求"：延时多久上电、老化测多长时间、真空低于多少算坏、温度上限多少。

**情况 A：多台用同一个要求** → 点右边【批量设置配方】：

![批量设置配方窗口](images/06-batchrecipe.png)
- 配方名称：从下拉选一个（比如"烧屏 8 小时"）。**只能选已有配方**，选不了就先去【配方管理】建；选中后延时/烧屏/温度/负压会自动填好。
- 延时时间：开阀后等多久才上电（等真空吸稳），格式"时:分:秒"；填 0 ＝ 不等，阀和电同时开、直接计时。
- 烧屏时间：就是老化时长，测多久。**烧屏/老化必须填！填 0 = 永远测不完。**
- 极限温度、负压阈值：按工艺卡填，不懂就问，不要自己编。
- 填完点 **【加入队列】** = 存下来 + 发到你选中的工位。

**情况 B：只调其中一台** → 点那台格子里的绿色【设置】按钮：

![单台工位设置窗口](images/07-stationsettings.png)

- 和批量窗口内容一样，只是只管这一台。
- 小窍门：格子右上角的选中框**点一下**就选中它（触摸屏手指点也一样），再点一下取消；面板上的【设置】按钮点哪台开哪台（不管勾了几个），想批量改多台点右边【批量设置配方】按钮。

**情况 C：新建/改配方本身** → 顶部菜单【参数设置】→【配方管理】（要技术员权限）：

![配方管理窗口](images/05-recipe.png)

- 左边是配方清单，右边改内容，【添加】【更新】【删除】点一下就自动存盘，没有"保存"按钮。
- 操作员一般不用进这里，用批量窗口选现成的就行。

### 第 ④ 步：选中工位，点【启动运行】

- 先选中要测的工位（点选中框或点格子空白处，可多选；点格子之间的缝隙不选中；每行还有"全选"按钮）。
- 点右边蓝色 **【启动运行】**，弹出确认框，确认人数/配方没错就点确定。
- 点完启动，软件**先只开真空阀吸产品，这时候不通电**，是安全的（延时填 0 的配方是阀和电同时开、直接计时，启动前和技术员确认好）。

三个必须知道的规矩（背下来）：

1. **参数启动那一刻就定死了**：启动之后你再改配方，正在测的不受影响，只对下一批新启动的有效。想改正在测的？先停掉重来。
2. **配方优先、全局兜底**：延时、时长、阈值先看配方里有没有填，配方没填才用全局设置。所以配方要填全。
3. **时长填 0 = 不限时长**：软件启动时会警告你。正式生产必须填时长；只有烧屏、调试才允许 0。
4. **SN 为空也能启动**（会警告），但以后查不到这台测的是哪件产品。正式生产必须扫码绑定。

### 第 ⑤ 步：巡检看着（不用一直守）

启动后软件自动走：**抽真空 → 真空吸稳 + 延时到 → 自动通电计时**（延时 0 的配方跳过等待、直接通电计时）。你每隔一段时间巡一圈，看格子的底色（对照下一节），浅粉/红了就去处理。

### 第 ⑥⑦ 步：时间到自动断电，取下产品

- 时长一到，软件自动断电、关阀，格子变淡钢蓝（待取料）。
- 人工把产品取下来就行。本机没有自动泄压、无响铃，拿的时候如果吸得紧拿不下，报给工艺（可能是要加泄压配置），不要硬拽。

### 第 ⑧ 步：复位回空闲

- 淡钢蓝的"完成"格、浅粉的"故障"格，**必须点【报警复位】才变回空闲**，点【停止运行】是清不掉的。
- 或者给它绑一个新的 SN（扫下一件产品），也会自动清掉完成状态。

## 五、格子底色对照表（认底色，看上电/真空块确认）

| 格子底色 | 是什么意思 | 你要做什么 |
| :--- | :--- | :--- |
| 白 | 空闲，这台没活，可以投料 | 扫码绑上就能启动 |
| 浅黄 | 测试中（抽真空没通电，或吸稳通电计时中，看上电块：灰＝没通电、绿＝通电计时） | 等着，不用管 |
| 淡钢蓝 | 时间到，自己断电了，待取料 | 取下产品，再点【报警复位】 |
| 浅粉 | 出问题了，软件已自动关阀断电 | 看下一节处理，不要直接复位重测 |

### 6.2 报警种类与动作（统一：关该台阀＋断电＋标红，只触发一次）

| 报警 | 大白话 | 现场处置 |
| :--- | :--- | :--- |
| 压力越限（产品 FAIL） | 真空变差了，超过能忍的线 | 查气管松/漏/产品没放好，处理好复位重测 |
| 真空建立失败（产品 FAIL） | 开阀 15 秒还没吸上 | 同上；好多台一起出现就查气源总阀 |
| 通讯失联（设备异常，不记产品坏） | 这台表连不上了 | 查该表电源/485 线；换表后复位 |
| 超温联停（可选，默认关） | 送风机温度超了 | 查风道堵没堵；温度回来后复位 |

合格口径：**全程没报警 ＝ PASS**；通讯失联不冤枉产品，只记设备异常。

### 6.3 三个最容易按错的按钮

| 按钮 | 效果 |
| :--- | :--- |
| 停止运行 | 停掉正在测的，回空闲，**不清红蓝屏、不记判定** |
| 报警复位 | 红（故障）/蓝（完成）回空闲，必须用它 |
| 全部停止（急停） | 全关阀＋全断电＋停风机＋清任务快照，有确认框；非紧急不用 |

### 6.4 断电/异常退出后

重启后如果弹恢复提示：按当班工艺要求选**整台重测**（已跑的作废、满时长重跑）或**放弃**（安全关阀断电）。

### 6.5 下料判定按钮

![下料判定窗口](images/11-unload.png)

本项目默认**自动 PASS**，这个按钮平时点了只会提示，不用管。只有工艺切到"待判定"模式后，完成的台才要在这里人工选 PASS/FAIL（FAIL 还要填不良代码、选处置）。

## 七、配方管理（操作员只看会用）

![配方管理窗口](images/05-recipe.png)

- 配方管理在顶部菜单【参数设置】里，要技术员权限；建配方改配方点一下就自动存盘，没有"保存"按钮。
- 配方四个数：延时时间 / 烧屏时间 / 负压阈值 / 显示模式（仅记录用）。
- 操作员记住两条红线就行：**时长填 0 ＝ 永远测不完**；**负压填 0 ＝ 真空保护没了**。看到配方里有 0 先问班组长。

## 九、历史记录（查、追溯）

![历史记录窗口](images/08-history.png)

- 顶部菜单【日志记录】→【历史记录】：选日期点【查询】，启动/报警/完成/判定全过程都在里面。
- 【导出】按管理员配好的列生成表格，直接发质量。

- MES 自动上报不用你管：数据会自动发给工厂系统；你要做的就是批号一次录对、每台条码扫对（这两样会进上报），收不到数叫技术员。

## 十二、每班点检（5 分钟）

1. 状态栏在线，面板没有大面积失联，离线台列清单报修不等人。
2. 扫码枪随便扫一条，有填充即正常。
3. 抽一台看压力跳动（1 秒一跳，定住不动查该表）。
4. 昨天历史记录能打开，追溯链不断。
5. 激活窗剩余天数小了就催商务续期。

---

## 十三、禁忌清单（不要做的事）

1. 测试中不用送风机测试窗手动停风机（会被自动重启）。
2. **两种阈值绝不混用**：软件报警阈值（kPa，不写设备）≠ 气压表设备阈值（写 0x0010）。
3. 烧屏/老化时长必填，0 ＝ 永远跑不完。
4. 急停会清任务快照，非紧急不用"全部停止"。
5. 中途改配方不影响在跑的台，要生效就重启动。
6. 通讯测试点动是真动作，别乱点整排遍历（确认→单点→听声/看灯）。
7. 激活码 30 个字符，抄全再输；`MainSetting.ini` 别删别拷到别的机。
