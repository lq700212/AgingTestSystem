```
空闲 ──[点启动]──► 只开真空阀，不带电（抽真空阶段）
                        │
        ┌───────────────┼───────────────┐
        │               │               │
   真空到位 且      超时还没到位        报警进入瞬间
   延时开启到       （默认15秒）        （只触发一次）
        │               │               │
        ▼               ▼               ▼
   载台上电，      报"真空建立失败"    关该台阀＋断该台电
   开始计时        记 FAIL             ＋面板标故障红
   （送风机：        永不带电
     首台在测
     即自动开；
     全停才停）
        │
   时间一到（配方
   里定的时长）
        │
        ▼
   自动下电＋关阀
   面板变蓝"已完成·待取料"（PASS）
```

- **随时可按**：手动停止＝中止回空闲；急停＝全部停掉；取走完成品后该工位回空闲。
- **断电来电**：重启询问"整台重测 / 放弃（安全关阀断电）"。
- **合格口径**：全程无报警＝PASS；压力报警＝FAIL（产品责任）；通讯失联＝设备异常（不记产品 FAIL）。
- 图里"延时开启""老化时长""负压阈值"三个数都来自配方，现场要定（见§三参数表）。

## 一、访谈必问（按对象，每题：问法 → 不同答案改什么）

### 对工艺

1. **真空到底干什么用的？**（G2，P0）
   当面问："漏气这台货，你们算治具问题还是产品不良？"
   - 治具问题 → 现状不动，只验阈值参数。
   - 产品不良 → 报警要关联 SN 记不合格，回来改判定逻辑（约 0.5~1 天）。
   追问一句："摆料时产品靠什么固定？一松手掉吗？"掉 → 加回"装夹预吸附"入口（带压力监控）。

2. **载台给产品供什么电？要不要监测电流？**（G1，P0）
   当面问："多少V？直流交流？谁供电？老化中看不看电流/功率？"
   - 要回采 → 加电流表通讯，最大工作量项，单独排期，**不当场承诺时间**。

3. **送风是加热还是冷却？温度谁说了算？超温停单台还是全线？**（G7，P0）
   - 软件设温 → 现协议无写温度寄存器，需找风机厂商，先记二期。

4. **老化合格谁说了算？在哪看结果？**（G5，P0）
   现状口径：全程无报警=PASS、压力报警=FAIL、失联=设备异常（不记产品 FAIL）。
   只确认：接受否 + 判定人 + 结果在哪看（屏幕/报表/MES）。

### 对操作员

5. **一批放多少？做完一个换一个还是一批同进同出？批号怎么定？混批吗？**（G6）
6. **到时完成后你们希望怎样？自动下电够吗，要不要自动泄压/响一声？**（G4）
7. **报警的货现在怎么处理？复位谁来按？**（G8）

### 对质量

8. **报表要什么样？最好直接拿一张现有纸质/Excel 照抄。**（G10）
   现状只有 CSV 明细 + 历史查询；直通率/曲线/SN 追溯单都要现做。

### 对电气/IT

9. **载台供电方式 + 真空管路走向 + 送风管道，拍照。**（G1/G2/G7）
10. **MES/ERP 有无硬性对接要求？接口形式？**（G9，有就µ单独排期）
